### Task 2: RAG-Based PDF Question Answering

**Folder:** `Task-2-RAG/`

A Retrieval-Augmented Generation (RAG) pipeline that loads multiple PDF documents, splits their text into chunks, generates embeddings, stores them in ChromaDB, and answers questions using retrieved context.

**Technologies:** Python, LangChain, Ollama, ChromaDB, PyPDF.

[View Task 2](./Task-2-RAG/README.md)
